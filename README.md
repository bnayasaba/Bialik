# תכנית ביאליק | מערכת נוכחות

אתר נוכחות בעברית, מותאם לטלפון, שבו הסטודנטים בוחרים את שמם ומדווחים: **נכחתי / לא נכחתי / מילואים**. דיווח נוכחות מזכה ב-7 שעות, וגם שבת הסטודנטים מזכה ב-7 שעות. מילואים אינם נספרים בשעות.

## המערכת
- **GitHub:** הקוד שבמאגר זה.
- **Vercel:** אירוח האתר, כולל פונקציית שרת ב-`api/attendance.js`.
- **Google Sheets:** בסיס הנתונים (פרטי), עם רשימות הסטודנטים, המפגשים, דיווחים וסיכומי שעות.
- **Google Apps Script:** הממשק המאובטח ברמת הרשאות Google לעריכה בגיליון, דרך הפונקציה של Vercel.

גיליון הנוכחות: https://docs.google.com/spreadsheets/d/1Y76RFQG5CtiQRQykAmdlQKQiW5UT0wHKs02tlUQJnlk/edit

## לוח מפגשים
רשומות בגיליון 14 פגישות ביום שלישי, 15 ביום רביעי, וכן שבת סטודנטים אחת (13-14.11.2026) לשתי הקבוצות. יום שלישי 27.10.2026 אינו נכלל בגלל הבחירות, ומפגשי 8-9.12 אינם נכללים בגלל חנוכה. יש לוודא מול הלו"ז הסופי את יתר התאריכים.

## הפעלה ראשונית (נדרשת פעם אחת)
1. פתחו את גיליון הנוכחות. בתפריט **הרחבות > Apps Script**, צרו פרויקט Apps Script והדביקו את כל התוכן שב-[apps-script/Code.gs](apps-script/Code.gs). שמרו.
2. ב-Apps Script: **Deploy > New deployment > Web app**. הגדירו **Execute as: Me**, ו-**Who has access: Anyone**. אשרו את ההרשאות הנדרשות, העתיקו את כתובת פריסת ה-`/exec` ושמרו אותה פרטית.
3. חברו מאגר זה ל-Vercel (או צרו פרויקט חדש שמקושר ל-`bnayasaba/Bialik`). השתמשו בהגדרת Framework Preset: **Other**.
4. ב-Vercel > Project > Settings > Environment Variables הוסיפו `APPS_SCRIPT_URL` ככתובת ה-`/exec` שקיבלתם. הגדירו גם ל-Production, ובצעו Redeploy.
5. פתחו את אתר Vercel, בחרו שם, שייכו לראשונה קבוצת שלישי או רביעי במידת הצורך, וסמנו דיווח. ודאו שהופיעה שורה בלשונית **דיווחים** בגיליון, ושהסיכום בלשונית **סטודנטים** השתנה.

### הערות
- **אין לשתף את הגיליון הפרטי עם הסטודנטים.** הדפדפן פונה רק לשרת באתר, ולא ישירות לגיליון.
- הרישום מבוסס על בחירת שם ללא הזדהות, כפי שהתבקש. לכן כל מי שיש לו קישור לאתר מסוגל לבחור שם אחר ולדווח בשמו. אם יידרש בעתיד אימות, ניתן להוסיף קוד אישי.
- קישור Apps Script נשמר כמשתנה סביבה ב-Vercel, לא בקוד הדפדפן או במאגר. אין לשתפו.
- אפשר לתקן שיוך קבוצה בגיליון. המפגשים המוצגים לסטודנט נקבעים לפי השיוך בגיליון.
- שינוי דיווח מעדכן את אותה רשומה, בלי ליצור ספירה כפולה.
