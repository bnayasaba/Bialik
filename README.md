# תכנית ביאליק: מערכת דיווח נוכחות

מערכת בעברית עם **GitHub** לקוד, **Vercel** לאירוח ו-**Google Sheets** לבסיס נתונים.

- **אתר:** https://bialik-attendance.vercel.app
- **גיליון:** https://docs.google.com/spreadsheets/d/1Y76RFQG5CtiQRQykAmdlQKQiW5UT0wHKs02tlUQJnlk/edit

## מצב נוכחי

האתר והגיליון נוצרו. **הדיווח לא יהיה פעיל עד להשלמת חיבור Apps Script ולהגדרת משתני הסביבה ב-Vercel.**

## הפעלה ראשונית

1. פתחו את גיליון הנוכחות. בחרו **הרחבות > Apps Script**.
2. העתיקו את מלוא הקוד שבקובץ [apps-script/Code.gs](apps-script/Code.gs) אל עורך Apps Script, שמרו.
3. ב-Apps Script > **Project Settings > Script properties** צרו:
   - `SHEET_ID` = `1Y76RFQG5CtiQRQykAmdlQKQiW5UT0wHKs02tlUQJnlk`
   - `API_TOKEN` = מחרוזת ארוכה וסודית שאינה מופיעה בקוד.
4. בחרו **Deploy > New deployment > Web app**, הגדירו **Execute as Me** ו-**Who has access Anyone**, אישרו גישה לגיליון. העתיקו את כתובת `/exec` של ההפעלה.
5. ב-Vercel, תחת **bialik-attendance > Settings > Environment Variables**, הגדירו:
   - `APPS_SCRIPT_URL` = כתובת `/exec` משלב 4
   - `APPS_SCRIPT_TOKEN` = אותה מחרוזת סודית שבחרתם בשלב 3
   יש להגדיר לשניהם Production ולבצע **Redeploy**.
6. בדקו דיווח נוכחות אחד ודאגו שאותו דיווח מופיע בלשונית **דיווחים** בגיליון. אפשר לאפס את דיווח הבדיקה באתר.

## כללי הנוכחות

- רשימת המשתתפים מוזנת מראש. כל סטודנט בוחר את שמו.
- שתי קבוצות: שלישי עם דוד נחמן ורביעי עם עמית ברץ. סטודנט שלא שויך יבחר קבוצה בפעם הראשונה.
- 14 מפגשים בשלישי, 15 ברביעי, ושבת סטודנטים משותפת ב-13 עד 14 בנובמבר 2026.
- מפגש שלישי ב-27.10.2026 בוטל בגלל הבחירות; מפגשי 8 ו-9 בדצמבר אינם כלולים בשל חנוכה.
- סטטוסים: **נכחתי = 7 שעות**, **לא נכחתי = 0**, **מילואים = 0 אך נספרים בנפרד**.
- ניתן לעדכן או לאפס דיווח, והוא לא ייספר פעמיים.

## פרטיות ואבטחה

אל תשתפו את גיליון הנוכחות עם הסטודנטים. לא נשמרים בקוד מספרי זהות, מספרי טלפון או מפתחות. המשתנים הסודיים אינם מופיעים בדפדפן או ב-GitHub.

שימו לב: על פי החלטת התכנית, אין הזדהות אישית. לכן **כל מי שמחזיק בקישור יכול לבחור שם אחר ולדווח בשמו**. זהו דיווח המבוסס על אמון.
